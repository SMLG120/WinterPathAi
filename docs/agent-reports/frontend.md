## Bugs found and fixed along the way
1. MapLibre v6 ESM worker URL broke under Vite → map never fired `load`, so no overlays loaded. Fixed with `setWorkerUrl(…?url)`.
2. `/pilot-requests` 201 with empty body was parsed as JSON and shown as a network error. Fixed with `parseAs: 'text'`.
3. `manualChunks` pulled the 3D vendor chunk into the entry's modulepreload (376 KB gz initial). Removed; initial is now 157 KB gz.
4. Motion's `reducedMotion="user"` still faded opacity. Sections now skip animation entirely under reduced motion (e2e-tested).
